# Security policy

## Reporting a vulnerability

Report suspected VM API vulnerabilities through [GitHub private vulnerability reporting](https://github.com/vm-api/vm-api/security/advisories/new). Do not report vulnerabilities in public issues or pull requests.

Include the affected version or commit, a description of the impact, and reproduction steps if available. Do not include credentials or unrelated sensitive data.

Project maintainers review reports privately and coordinate fixes and public disclosure with the reporter. Report vulnerabilities specific to an infrastructure provider through that provider's security process.

## Supported versions

Security fixes currently target `main`. We will document supported release versions here as versioned releases become available.
