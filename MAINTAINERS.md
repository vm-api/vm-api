Use public [issues](https://github.com/vm-api/vm-api/issues) and [pull requests](https://github.com/vm-api/vm-api/pulls) for project discussions. Send vulnerabilities through [private reporting](https://github.com/vm-api/vm-api/security/advisories/new), never a public issue.

This roster records responsibility for this repository. Maintainer additions, departures, and scope changes must be recorded in a reviewed PR. Organization ownership and CNCF metadata should be reconciled when the roster changes. The project welcomes maintainers from any organization; no employer receives reserved authority.
