# Code of Conduct

VM API adopts the [CNCF Community Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md). It applies to contributors, maintainers, and participants in project spaces and project-related activities as described in that policy.

Report conduct concerns privately to the CNCF Code of Conduct Committee at [conduct@cncf.io](mailto:conduct@cncf.io). The [incident resolution procedures](https://github.com/cncf/foundation/blob/main/code-of-conduct/coc-incident-resolution-procedures.md) describe reporting options, including anonymous reports. Do not put confidential conduct reports in public issues.

For CNCF events, follow the event-specific reporting contacts in the CNCF policy. Software vulnerabilities belong in the project's [private security report form](https://github.com/vm-api/vm-api/security/advisories/new).
